# Онлайн магазин за ски екипировка (Docker проект)

## Описание на проекта

Този проект представлява уеб приложение (онлайн магазин за ски екипировка), разработено с **PHP, HTML, CSS** и **MySQL** база данни.
Проектът е контейнеризиран с помощта на **Docker** и **Docker Compose**.

---

## Как се изграждат и стартират контейнерите

### 1. Клониране на проекта

```bash
git clone <https://github.com/Soner22224Deniz/HomeworkOS>
cd ski-project
```

### 2. Стартиране на контейнерите

```bash
docker compose up --build
```

### 3. Достъп до приложението

Отваря се в браузър:

```
http://localhost:8080
```

## Как работят компонентите

### 1. Уеб услуга (PHP + Apache)

* Изградена чрез собствен Dockerfile
* Стартира PHP приложението
* Обработва всички заявки от потребителя
* Достъпна на порт **8080**

### 2. База данни (MySQL)

* Използва официален Docker образ: `mysql:8.0`
* Съхранява информация за потребители, продукти, поръчки и др.
* Конфигурирана чрез `docker-compose.yml`

---

## 🔗 Комуникация между услугите

Комуникацията между контейнерите се осъществява чрез Docker Compose.

* Уеб приложението се свързва към базата данни чрез името на услугата:

```
db
```

* Пример за връзка в PHP:

```php
$host = "db";
```

* Docker автоматично създава мрежа, в която контейнерите комуникират чрез имената си.
